# RolloBase public sharing copy

The static website serves Spanish, English, Traditional Chinese, Simplified
Chinese, Russian and Japanese. Homepages are `/`, `/en`, `/zh`, `/zh-cn`,
`/ru` and `/ja`. All six sample forms support BOPP and A–D presets, a
prefilled WhatsApp message and a downloadable copy. The Spanish mobile sample
form keeps technical fields in an optional disclosure.

The refrigerated-bottle guide is available at
`/guia-bopp-botellas-refrigeradas` and `/cold-bopp-ja`. Each links to a
localized blank trial CSV, BOPP product and preselected sample request.
Public page links use extensionless paths and preserve queries and anchors.
Chinese pages use independent `zh-Hant` and `zh-Hans` alternate URLs.
Reviewed buyer guidance lives in `seo-content.json`; Simplified Chinese copy is
checked into `simplified.json`. Builds fail if Chinese source text lacks a translation.
The asset archive contains the stylesheet and licensed photos. The sample form
script is maintained as `buyer.js`.

`design_update.py` applies the shared application-first layout, the five-part
product specification format and the user-provided business telephone across
the original locales. Japanese content and equivalents are generated by
`japanese.py` using `japanese.json`.

## Deploy

- Service: Render Static Site. This must remain a static site, not a web service.
- Build command: `python3 deploy_build.py`
- Publish directory: `dist`
- Runtime dependencies: Python standard library only.
- `render.yaml` contains the route table. Keep the active Render rules in sync
  with it. Serve only the enumerated clean page routes from `dist/_pages`;
  a catch-all rewrite can return an empty 200 for missing URLs.
- Existing catalog aliases and `/index.html` redirect before the generic
  `/:page.html` rule. An old sample URL must redirect directly while retaining
  its query string. A clean URL must return HTML, and a missing page must return 404.
- When adding pages, run the build, refresh the route table with
  `python3 publish_paths.py` if requested by the build, then rebuild.
- Canonical URLs, language alternates and the sitemap use the host's assigned
  `RENDER_EXTERNAL_URL`, or an explicitly configured HTTPS `SITE_ORIGIN`.
- Publish only `dist`, without access protection or visitor authentication.

After deployment, test the six homepages, mobile comparison table, sample
presets, WhatsApp drafts, language alternates, sitemap, and old and missing URLs.
